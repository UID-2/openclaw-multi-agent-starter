# 06 — The Five Ways Multi-Agent Setups Rot (and the Fix Line for Each)

| # | Failure Mode | Symptom in Logs / Transcripts | Root Cause | Exact Fix Line |
|---|---|---|---|---|
| 1 | Silent Stale Session Pins | Nightly cron or wake fails with 404 This model was not found even after openclaw.json was updated | Per-session SQLite state or a cron job's payload.model still holds a retired model ID from weeks ago | Audit all sessions via session_status (model: default) and check openclaw cron get <id> for stale payload.model overrides. |
| 2 | Deferred-Tool Discovery Loops | Worker burns 5–7 calls on tool_search / tool_describe and times out before writing its file | Enabling tool_search/tool_describe on a non-exec agent flips it into Deferred Schema Mode | Keep tool_search and tool_describe in tools.deny on non-exec crew agents so tools.allow schemas project directly. |
| 3 | Compound Scope Inflation | Stage 1's 'one of the most common' becomes Stage 2's 'the #1 blocker' and Stage 4's overstated revenue table | Downstream stages trust upstream prose summaries instead of checking raw evidence files and re-deriving math | Require the Verifier (Stage 5) to audit Stage 1 quotes against 00-live-search-raw.json and recompute every financial row from per-unit formulas. |
| 4 | Single-Provider 429 Cascade | Resident agent aborts after 9 retries (RESOURCE_EXHAUSTED or 120s idle timeout) | Strict session /model override bypasses model.fallbacks, or all fallbacks sit on the same upstream provider | Set the target model as model.primary in openclaw.json with a cross-provider fallback chain and clear the session override (model: default). |
| 5 | Hub-and-Spoke Bottleneck | Orchestrator turn hits 2-minute timeout waiting on 4 sequential stages in a single cell | Orchestrator relays massive inline prompts and runs slow CLI subprocesses inside a 10s guest budget | Use File-Pointer Briefs, run independent stages (Spirograph + Boomerang) in parallel via Promise.all, and enforce <=2 tool calls per stage. |
